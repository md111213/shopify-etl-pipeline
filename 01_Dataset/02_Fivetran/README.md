- # Fivetran

Fivetran was used as the ETL tool to extract e-commerce data from Shopify and load it into Snowflake for further analysis.

## Connection Setup

Configured a Shopify connector in Fivetran to connect the Shopify data source with the Snowflake destination.

## Synchronization Details

Fivetran synchronized the Shopify data and transferred the required source data into Snowflake tables for analysis.

## Screenshots

This folder contains screenshots of the Fivetran connector setup, synchronization status, and configuration.

## Configuration Notes

- Shopify was configured as the source.
- Snowflake was configured as the destination.
- Required connector settings and permissions were configured.
- Data synchronization was monitored through Fivetran.
